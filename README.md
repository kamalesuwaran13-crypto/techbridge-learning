# TechBridge Learning

A public, independent technology-learning platform for exploring curated learning resources and original course outlines.

## Current version

This repository currently contains a responsive static website in `index.html`.

Features:
- Responsive landing page and course catalogue
- Search and filters for NPTEL resources and original courses
- Course detail popups with module outlines
- Clear attribution and independence notice for NPTEL/SWAYAM resources
- No account or backend required for this first public version

## Deploy on Vercel

1. Sign in to [Vercel](https://vercel.com/).
2. Select **Add New → Project**.
3. Import `kamalesuwaran13-crypto/techbridge-learning` from GitHub.
4. Keep the framework preset as **Other** (static site).
5. Leave the build command and output directory blank/default; the site entry point is `index.html` in the repository root.
6. Select **Deploy**.
